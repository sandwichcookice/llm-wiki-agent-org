# LLM Wiki：agent-org

TAICA 生成式 AI 第十週作業（雲科 B11517038 資工 郭益閎）。由 Claude Code 維護的 LLM Wiki，主題是我自己做的 Claude Code plugin「agent-org」，再只用這個 Wiki 產生教學 HTML 簡報。

- 網站（GitHub Pages）：https://sandwichcookice.github.io/llm-wiki-agent-org/
- 規則檔：`CLAUDE.md`（Wiki 格式、先討論後生成、lint 規則）
- Wiki 原檔：`wiki/`；討論與 ingest 紀錄：`wiki/log.md`
- 簡報資料與產生器：`slides/build/`；成品：`slides/index.html`
- 檢查腳本：`scripts/lint_wiki.py`、`scripts/check_slides.py`；網站產生：`scripts/build_site.py`
- 執行與檢查紀錄：`logs/run_log.md`、`logs/check_*.md`

`raw/` 原文沒有公開：裡面是私人 repo 的完整內容與對話摘錄。
